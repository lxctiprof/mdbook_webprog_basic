데이터 활용

[활용] 내가 만든 테이블을 이용해 도근 관리하기

CRUD

Create(생성), Read(읽기), Update(수정), Delete(삭제) 를 뜻함

  • 데이터 생성 : insert 문
  • 데이터 읽기 : select 문
  • 데이터 수정 : update 문
  • 데이터 삭제 : delete 문

자료 생성

  • CRUD 중 C(Create)에 해당

  • 문구

insert into [테이블 명] ( [필드명], [필드명], ... ) values ( [값], [값], ... );
  • 필드명과 값은 순서대로 짝이 맞아야 함.

예

insert into dogun ( x, y, coord, name, memo ) values 
( 10.5154, 7.8815, 15, '도근점1', '연석 위에 있음');

입력한 자료 확인

  • CRUD 중 R(Read)에 해당

  • 문구

select [필드명] 
from [테이블명]
where [조건]
order by [정렬할 기준이 되는 필드]

예

select * from dogun;

» dogun 테이블의 모든 자료를 가져온다. 조건이 없으니까.

select *

모든 필드를 가져올 때는 필드명을 다 적지 않고 *로 표시
비효율적(시간 오래 걸림, 서버 메모리 많이 사용, 네트워크 많이 사용)
필요한 필드만 적어야 가장 효율적으로 CPU, 메모리, 네트워크를 사용하게 됨.

select * from dogun의 문제점

select * from dogun;

초보인 내가 보기에도 테이블 자료에 문제가 있어 보인다.
문제점을 얘기해 보자.

조건에 따른 검색

1. “이름이 ’도근5’인 도근점“

select * from dogun where name = '도근5';
select * from dogun where name = '도근점 5';

2. 조건이 여러 개인 검색

select * from dogun where name='도근점 5' and memo = '잘 안보임';

실습

1. dogun 테이블에서 이름이 ’도근점 1’인 도근점의 모든 필드 검색

2. dogun 테이블에서 이름이 ’도근점 1’인 도근점의 x 필드만 검색

3. dogun 테이블에서 이름이 ’도근점 1’인 도근점의 y 필드만 검색

4. dogun 테이블에서 이름이 ’도근점 1’인 도근점의 메모 필드만 검색

5. dogun 테이블에서 이름이 ’도근점 4’인 도근점의 x, y 필드 검색

6. dogun 테이블에서 이름이 ’도근점 4’인 자료의 name, memo 필드 검색

7. dogun 테이블에서 x 좌표가 10.0 이하인 자료

8. dogun 테이블에서 y 좌표가 10.0 이상인 자료

like 연산자

공사 ERP에서 문서 검색할 때 꿀팁

연간 측량 계획, 연간 휴가 계획, 연간 인사 관리 계획 등 연간 ~ 계획을 검색하고 싶다면?

문서 검색에서 연간%계획 이라고 입력

전체 일치가 아닌 부분 일치되는 자료를 찾기 위해 사용

  • 예: 이름이 ’도근’으로 시작하는 도근점만 찾기
select * from dogun where name like '도근%';

like 연산자를 쓸 때의 % 기호

  • 모든 문자라는 뜻.

  • like ‘나%’ : ’나’로 시작되는 모든 자료, 예: ‘나지적’, ‘나영성’ 등

  • like ‘%나’ : ’나’로 끝나는 모든 자료, 예: ‘오빛나’, ‘아맛나’ 등

  • like ‘%나%’ : 자료 중 ’나’가 들어간 모든 자료, 예: ‘일어나’, ‘가나다’ 등

공사 ERP에서 문서 검색할 때 벌어지는 일

연간 측량 계획, 연간 휴가 계획, 연간 인사 관리 계획 등 연간 ~ 계획을 검색하고 싶다면?

문서 검색할 때 연간%계획 이라고 입력

select * from 공문 where title like '연간%계획';

실습

1. dogun 테이블에서 이름에 ‘도근’ 이 들어간 모든 자료 검색

2. dogun 테이블에서 메모에 ’연석’이 들어간 모든 자료 검색

3. dogun 테이블에서 메모가 ’연석’으로 시작하는 모든 자료 검색

4. dogun 테이블에서 메모가 ’연석’으로 시작하고 이름에 ’도근’이 들어간 모든 자료 검색

5. dogun 테이블에서 이름에 ‘도근’ 이 들어가고 x 좌표가 10.0 이상인 모든 자료 검색

6. dogun 테이블에서 메모에 ’수풀’이 들어가고 y좌표가 10.0 미만인 모든 자료 검색

7. dogun 테이블에서 메모가 ’연석’으로 시작하고 x좌표가 10.0 초과인 모든 자료 검색

oder by

쿼리할 때 검색결과에 나오는 순서를 정해줄 수 있다

예: 나이 순으로 정렬, 나이의 역순으로 정렬

select * from dogun order by name;
select * from dogun order by name desc;	»  이름의 역순으로 정렬

order by 뒤에는 여러 필드를 정해줄 수 있다. 이 때 필드의 순서대로 우선순위를 갖는다.

select * from dogun order by name, x;

먼저 이름의 가나다 순으로 정렬하고, 이름이 같은 도근점들이 있으면 그 도근점끼리는 x 좌표 순으로 정렬한다.

실습

1. dogun 테이블에서 X좌표 순으로 정렬

2. dogun 테이블에서 Y좌표 순으로 정렬

3. dogun 테이블에서 메모의 가나다 순으로 정렬

4. dogun 테이블에서 이름이 ’도근점 4’이 자료들만 X 좌표 순으로 정렬

5. dogun 테이블에서 이름에 ’도근’이 들어가고 x좌표가 10.0보다 큰 모든 자료 검색해 이름 순으로 정렬하고, 이름이 같은 도근점이 있으면 y좌표 순으로 정렬

6. dogun 테이블에서 메모에 ’연석’이 들어가고 y좌표가 10.0보다 작은 모든 자료 검색해 이름 순으로 정렬하고, 이름이 같은 도근점이 있으면 x좌표 순으로 정렬

입력한 자료 수정

  • CRUD 중 U(Update)에 해당

  • 문구

update [테이블명] set [필드명] = [값]
where [조건]

예

* 아래 코드는 강사만 실행한다.

update dogun set name = '도근점';

* dogun 테이블의 모든 자료의 name을 ’도근점’으로 바꾼다

입력된 자료 수정 시 where 절

이름이 ’도근점 1’인 자료를 찾아 메모를 ’중앙선 바로 위’로 바꾼다.

update dogun set memo = '중앙선 바로 위' where name='도근점 1';

* update 문을 쓸 때는 where 절을 먼저 써 놓는 버릇을 들여 전체 데이터의 값을 바꾸는 실수를 하지 않도록 하자.

실습

1. dogun 테이블에서 이름이 ’도근점 2’인 자료의 x 좌표를 바꾸자.

2. dogun 테이블에서 메모에 ’연석’이 들어간 자료의 x, y 좌표를 0, 0으로 바꾸자.

입력한 자료 삭제

  • CRUD 중 D(Delete)에 해당

  • 문구

delete from [테이블명] 
where [조건]

예

* 아래 예제는 실제 해보지는 말자

delete from dogun;

* dogun 테이블의 모든 자료를 삭제한다.

테이블 자체는 남아있음. 자료만 삭제되는 것.

입력한 자료 삭제 시 where 절

예

delete from dogun where name='도근점 1'

* 이름이 ’도근점 1’인 자료를 찾아 모두 지운다.

* delete 문을 쓸 때는 where 절을 먼저 써 놓는 버릇을 들여 전체 데이터를 모두 삭제해 버리는 일이 없도록 하자.

실습

1. dogun 테이블에서 이름이 ’dogun 2’인 자료를 삭제하자.

2. dogun 테이블에서 메모에 ’연석’이 들어간 자료를 모두 삭제하자.

3. dogun 테이블에서 이름이 ’도근’으로 시작하고 x 좌표가 10.0 이상인 모든 자료를 삭제하자.

4. dogun 테이블은 남겨두고 dogun 테이블의 모든 자료를 삭제하자.
