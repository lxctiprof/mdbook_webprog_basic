공간 데이터베이스 생성

1. 실습 자료

  • 필요한 프로그램

    • PostgreSQL: 데이터베이스 서버

    • PostGIS: PostgreSQL에 공간데이터 타입과 함수를 추가하는 확장

    • QGIS: 공간데이터 조회와 지도 시각화

    • pgAdmin(또는 DBeaver): SQL 실행 도구

  • 실습 자료 목록

2. 실습 환경 설정

  • 공간데이터베이스 생성

    • 새로운 데이터베이스를 생성하기 위해 Databases를 선택하고 마우스 오른쪽 클릭하여 Create > Database를 선택

      • Database: gis

      • Owner: postgres

  • Postgis 설치

    • 생성된 데이터베이스에서 Extentions > Create > Extension을 선택하여 Postgis를 설치

      • Name: postgis

      Query Tool > CREATE EXTENSION postgis;로도 설치 가능

    • Postgis 확장 모듈이 정상적으로 추가되었는지 확인을 위해 Query Tool > SELECT postgis_version() 입력 후 실행 버튼(또는 F5) 클릭

3. QGIS 개요

  • OSGeo(Open Source Geospatial Foundation)

    • 지리공간기술과 데이터의 공개 협업 개발을 지원하고 알리기 위한 비영리, 비정부 단체

    • 지리공간 분야의 오픈 소프트웨어와 오픈소스 개발을 폭넓게 재정적, 조직적, 법적으로 지원하기 위해 2006년 2월 4일 미국 시카고에서 창설

  • 오픈소스 소프트웨어(FOSS, Free and Open Source Sofrware)

    • 특정 라이선스에 따라 소프트웨어의 소스코드가 공개되어 있음

    • 소프트웨어에 대한 자유로운 이용, 복사, 수정 및 재배포의 권한을 부여 받음

      • Freedom of Use

      • Freedom of Copy

      • Freedom of Modify

      • Freedom of Redistribute

    • 사용 시 발생하는 문제는 저작자가 아닌 사용자의 책임

    • 사용 후 생상된 데이터 등은 사용자에게 권한이 있음

  • QGIS 설치 및 실행

    • QGIS 공식 홈페이지(http://qgis.org)로 접속하여 Download 버튼 > Skip it and go to download > Long Term Version for Windows를 클릭

      • 장기지원버전(Long Term Release) 버전은 1년 이상 계속적인 업데이트를 하는 버전

    • 다운로드 폴더 내 설치파일(QGIS-OSGeo4W-버전.msi)을 더블 클릭하여 실행

      • 별다른 특이사항 없이 [Next] 버튼 클릭하여 설치 진행

    • 시작메뉴에서 QGIS Desktop 버전 또는 바탕화면의 QGIS 버전 폴더에서 QGIS Desktop 버전을 클릭

      • GRASS GIS 버전: Geographic Resources Analysis Support System

      • OSGeo4W Shell: 오픈소스 GIS 프로젝트에 사용하는 윈도우 활용 쉘

      • SAGA GIS 9.3.1: System for Automated Geoscientific Analyses
