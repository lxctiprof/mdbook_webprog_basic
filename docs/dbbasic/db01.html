데이터베이스개념

데이터베이스

정의

  • 데이터의 집합
  • 개인이 데이터를 정리하기 위해 시작했지만 이후로는 주로 여러 명이 데이터를 공유하기 위한 목적으로 데이터를 모아 놓은 것을 말함

DBMS

  • DataBase Management System : 데이터베이스를 관리하는 시스템

  • 여러 명이 접속해서 데이터베이스(자료)를 입력하고 사용할 수 있도록 해 주는 시스템

    • oracle
    • mysql
    • ms-sql
    • postgreSQL

DBMS vs DB

  • DBMS: DataBase Management System

  • DB: DataBase

DB를 잘 관리하도록 해주는 시스템(프로그램)이 DBMS.

postgreSQL

  • 발음: [포스트그레스큐엘] [포스트그레스] 혹은 [포스트그레]라고도

  • 무료

  • open source

  • 상용에 준하는 성능과 기능

  • ORDBMS(Object-Relational DBMS)

  • postgis 라는 공간정보에 특화된 확장 기능 제공

    • 공사가 postgreSQL을 잘 알아야 하는 이유

postgreSQL의 공간정보 특화 기능

  • postgis라는 extension을 이용해 아래 공간정보 특화 기능 처리

  • 점 하나, 선 하나, 면 하나 정보 처리

  • 점 여러 개, 선 여러 개, 면 여러 개 정보를 하나의 자료로 처리

  • 좌표체계간 변환(중부원점 ↔ WGS84)

  • 공간정보 계산

    • 곡면을 고려한 거리, 면적 계산

    • 점A가 면 B 안에 포함되는지 여부 확인

AI 시대 데이터베이스를 배우는 이유

  • 코딩은 AI가 해준다. 자료 저장만 되면 내가 직접 꽤 그럴듯한 프로그램을 만들어 볼 수 있을텐데

(실 사례) 아이 영어 단어 외우기 앱을 만들어 아이 공부에 활용

  • 아이가 너무 좋아함. 엄마랑 같이 만드는 영어 공부 앱.

  • 재밌는 영어 공부 앱

  • (단점) 학습 기록을 남기지 못한다. DB를 몰라서.

AI 시대에 돈 버는 회사

  • 프로그램을 잘 만드는 회사(X)

  • 데이터를 많이 쌓아놓은 회사(O)

  • 인프라, 브랜드를 구축해 놓은 회사(O)

    • 유통망
    • 많은 회원
    • 많은 사용 경험(입소문, 후기 등)

(강사가 만든) 가장 간단한 데이터베이스 프로그램

팟캐스트 몰아듣기(정주행) 앱 개발

  • 약 100개의 회차를 가진 팟캐스트를 1화부터 쭉 이어듣고 싶었음
  • 프로그램이 꺼질 때 다음 2개 정보를 저장
    • 프로그램 회차
    • 재생 위치
    • 예: [2회차 07:10]
  • 프로그램이 시작되면 데이터베이스에서 그 2개 정보를 가져와 마지막 들은 곳부터 재생 시작
