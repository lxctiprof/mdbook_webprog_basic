PostGIS와 공간 데이터베이스

1. 공간 자료의 특징

  • 비정형성

    • 각 공간 개체의 내용 및 구조가 개체 형식에 따라 다르게 표현

    • 같은 형식 간에도 점의 개수 및 서브 개체의 개수 등에 의하여 다른 형태와 길이를 가짐

  • 대용량성

    • 일부 공간데이터의 경우 DBMS의 한 페이지를 넘는 크기를 가질 수 있음

2. 공간데이터베이스의 특성

  • 자료의 크기와 복잡성

    • 공간 데이터는 위치 정보를 갖는 도형자료와 그 도형의 특성을 나타내는 속성정보로 구성

    • 자료의 양이 클뿐만 아니라 위상 정보를 갖는 만큼 자료의 구조도 복잡함

  • 공간 전용 질의 및 인덱싱

    • 일반 데이터베이스에서 다루지 않는 공간 형식의 데이터를 처리하므로 이에 적합한 함수가 존재

    • 이를 이용한 공간 전용 질의가 가능하며, 질의 효율을 높이기 위한 공간 전용 인덱싱 기법이 적용

      • 현재 위치에서 가장 가까운 병원은 어디인가?

      • 서울특별시의 면적은 얼마인가?

      • 서울특별시를 지나는 도로의 길이는 몇 km인가?

3. 공간데이터베이스의 구성 요소

  • 구성요소

    • 공간 데이터 모델, 공간 참조 시스템, 공간 데이터 전용 질의, 공간 인덱스

  • 공간 전용 질의

    • SQL을 이용하는 방식과 거의 동일하게 공간 질의어를 이용 가능

    • 공간 질의의 종류는 데이터 정의어(DDL)와 공간 데이터 관련 함수로 구성

    • 데이터 정의어를 이용한 공간 질의

      • 테이블을 생성하고, 인덱스를 생성하는 부분은 일반 데이터베이스와 동일하지만, GEOMETRY 형식의 컬럼 생성

      • GEOMETRY 칼럼에는 점, 선, 면 등으로 정의된 데이터 모델을 따르는 공간 데이터가 저장

    • 공간 데이터 관련 함수

      • SELECT, INSERT, UPDATE, DELETE 등의 질의를 수행할 때 공간 데이터는 공간 함수와 같이 쓰는 경우가 대부분

      • 공간 데이터 변환, 좌표 변환, 면적 계산, 거리 계산, 인접한 개체 탐색 등 공간 데이터와 관련된 수 많은 함수를 공간 데이터베이스에서 지원

  • 공간 인덱스

    • 공간 데이터 전용 질의를 수행하기 위해서는 효율적으로 데이터에 접근할 수 있는 기법 필요

    • 저장된 많은 양의 공간 데이터에 대하여 실제 처리해야 할 개체의 집합을 줄이는 효율적인 공간 접근 방법(Spatial Access Method, SAM) 개발

      • 공간 접근 방법: 공간 인덱스를 사용하여 공간 질의에 대하여 처리될 개체의 수를 줄이고자 하는 방법

4. PostGIS 소개

  • PostGIS란

    • PostgreSQL의 공간 기능을 추가하는 확장(Extension)

    • PostgreSQL이 공간데이터베이스의 역할을 할 수 있도록 해주며 다양한 장점을 가짐

      • 다양한 공간 함수와 연산 제공, 복잡한 쿼리와 분석 지원, 대규모 데이터셋에서도 높은 성능

    • 공간데이터베이스의 세 가지 핵심 요소(공간 형식, 공간 인덱스, 공간 함수)를 PostgreSQL에 추가

      • 공간 자료형: geometry(평면), geography(구면, 위경도 기반), raster

      • 공간 함수 : 300개 이상 (ST_로 시작)

      • 공간 인덱스: GiST 인덱스로 빠른 검색

      • 좌표계 변환: 수천 개 좌표계 내장

  • PostGIS 메타 정보

이름역할
spatial_ref_sys좌표계 정의 목록
geometry_columns어떤 테이블의 어떤 컬럼이 geometry인지 목록

  • SQL 기초 복습

-- 연습용 테이블
CREATE TABLE edu.sample_place (
    id    serial PRIMARY KEY,
    name  text,
    kind  text,
    geom  geometry(Point, 4326)
);

INSERT INTO edu.sample_place (name, kind, geom) VALUES
 ('서울시청', '관공서', ST_SetSRID(ST_MakePoint(126.9784, 37.5666), 4326)),
 ('경복궁',   '관광지', ST_SetSRID(ST_MakePoint(126.9770, 37.5796), 4326)),
 ('남산타워', '관광지', ST_SetSRID(ST_MakePoint(126.9882, 37.5512), 4326));

SELECT * FROM edu.sample_place;                           -- 전체
SELECT name FROM edu.sample_place WHERE kind = '관광지';   -- 조건
SELECT kind, count(*) FROM edu.sample_place GROUP BY kind;-- 집계
SELECT name, ST_AsText(geom) FROM edu.sample_place;       -- 공간 → 텍스트
