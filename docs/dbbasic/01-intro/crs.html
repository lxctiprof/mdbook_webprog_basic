좌표계와 SRID

1. 좌표체계의 개념

  • 좌표체계의 필요성

    • 모든 공간정보 자료는 정확한 위치를 가지고 있어야 함

    • 좌표 정보를 이용해 임의의 점이 지표 위 어느 지점에 위치해 있는지 표현 가능

      • 좌표의 원점, 거리 단위, 방향 등의 정보 필요

  • 좌표체계의 개요

    • 어떤 점의 위치를 설명하기 위한 규정의 집합

    • 한 점의 위치를 표현하기 위해 사용

    • 사용하는 좌표체계에 따라 좌표 값이 달라짐

      • 사용하는 자료의 좌표계를 정확히 알지 못하면 동일한 대상물이 서로 다른 곳에 표시되는 문제점 발생

  • 좌표체계의 개념

    • 지표 상의 위치를 정의하기 위한 기준 프레임

    • 지리좌표체계(Geographic Coordinate System)

      • 3차원의 구면을 이용하는 좌표계

      • 경도(Longitude)와 위도(Latitude) 값으로 위치 지정

      • 지구 중심에서 지표면 상에 지점까지 측정된 각

    • 투영좌표체계(Projected Coordinate System)

      • 지리좌표를 평면 상에 투영한 좌표계

      • 하나의 타원체를 투영하는데 다양한 방식의 투영법 존재

2. 지리좌표체계(Geographic Coordinate System)

  • 지오이드(Geoid)

    • 실제 지구모양에 가깝도록 나타낸 것

    • 평균해수면을 육지까지 연장한 가상적인 면

    • 중력 방향에 수직인 (등)포텐셜면

    • 지구 상에서 높이를 측정하는 기준이 되는 면

  • 타원체(Ellipse)

    • 지구타원체

      • 지구 모양과 가장 비슷한 형상을 가지고 있는 타원체

    • 준거타원체

      • 어느 지역의 측지측량계의 기준이 되는 타원체

    • 국제표준타원체

      • 전 세계적으로 측지측량계를 통일하기 위한 지구 타원체

  • 지리좌표체계

    • 3차원의 구면을 이용하는 좌표계

3. 투영좌표체계(Projected Coordinate System)

  • 투영(Projection)

    • 3차원의 타원체에 그려진 경위도 선을 평면(2차원)의 지도에 나타낼 수 있도록 체계적으로 변환하는 것

    • 지표면(3차원)에 위치한 객체의 형상과 면적, 거리, 방향 등을 2차원의 지도에서 그대로 정확하게 나타내는 것은 불가능

    • 지도 제작 시에 고려해야 하는 요소

      • 정형성: 지도 상에서의 모양이 지표면 상의 실제 모양과 동일한가?

      • 정적성: 지도 상에서의 면적이 지표면 상의 실제 면적과 같은 비례로 나타나는가?

      • 정거성: 지도 상에서 두 지점들 간의 거리가 지표면과 같은 관계를 유지하는가?

    • 지구본과 같은 3차원의 구체(또는 타원체)를 평면으로 투영하게 되면 이러한 특성이 왜곡되어 나타남

  • 투영법

    • 3차원인 지구를 2차원 평면으로 펼칠 때 어떤 기하학적 곡면(투영면)을 사용하는 지에 따라 분류

    • 원통도법(Cylindrical Projection)

      • 적구나 특정 표준위선을 따라 지구를 둘러싼 원통면에 투영한 뒤 펼침

      • 대표적인 예: 메르카토르, TM(횡축 메르카토르), UTM

    • 원추도법(Conic Projection)

      • 지구본 위에 원뿔을 씌운 형태로 투영한 뒤 펼침

      • 대표적인 예: 람베르트 정각원추, 알버스 정적원추

    • 방위도법(Azimuthal / Planar Projection)

      • 지구의 한 점(주로 극지방이나 특정 지점)에 평면을 접하게 하여 투영

      • 대표적인 예: 정거방위, 정사, 평사, 심사

  • 평면직각 좌표계

    • 평면의 2차원상에서 공간정보의 위치를 표현하기 위한 방법

    • X축과 Y축이 원점(0, 0)을 중심으로 직각으로 만나고 원점에서 떨어진 거리로 좌표를 표현

    • 좌푯값이 양수와 음수 모두 가질 수 있으므로 경우에 따라 가산값을 부여하여 양수화

4. 우리나라의 좌표체계

  • 세계측지계 사용

    • 세계측지계(ITRF계 GRS80 타원체)와 한국측지계(동경데이텀)를 병행 사용하다가 2010년 1월 1일부터 세계측지계의 사용을 의무화

      • 동경측지계: 타원체 Bessel1841, 적도반경 6,377,397.155m, 극반경 6,378,137.000m

      • 세계측지계: 타원체 GRS80, 적도반경 6,377,137.000m, 극반경 6,356,752.341m

  • 공공측량의작업규정세부기준

5. 공간참조체계

  • 공간참조체계의 개념

    • 타원체, 좌표체계(직각, 경위도), 투영법이 조합되어 하나의 공간참조체계(Spatial Reference System, SRS)를 구성

      • 공간참조식별자(Spatial Reference Identifiers, SRID) 또는 좌표참조체계(Coordinate Reference Systems, CRS)라고도 함

    • EPSG(European Petroleum Survey Group)*에서 전 세계의 다양한 좌표계를 표준 코드화 하여 3~6자리의 숫자인 코드로 관리하여 공개

      • 우리나라에서 사용되는 공간참조체계의 구체적인 정의는 https://epsg.io에서 확인 가능
