  • 처음 이용하는 사용자에게 적합

netlify를 이용해 웹서버에 올리는 방법

https://profkim2000.github.io/board/geo3d/deploy/netlify.html

실습: 위치정보 프로그램을 netlify에 올려 스마트폰에서 실행하고 걸어다니며 좌표 변하는 것 확인

1. d:\test\html5\gps 폴더에 gps.html 파일 생성

d:\test\html5\gps\index.html 파일의 내용

<html>
  <head>
    <script>
       navigator.geolocation.getCurrentPosition( (position) => {
        const lat = position.coords.latitude;
        const lon = position.coords.longitude;
        const accuracy = position.coords.accuracy;

        document.write(`위도: ${lat}`);
        document.write("<br>")
        document.write(`경도: ${lon}`);
        document.write("<br>")
        document.write(`정확도: ${accuracy} 미터`);
       });
    </script>

  </head>
  <body>    
  </body>
</html>

2. netlify를 이용해 웹서버에 업로드

https://netlify.com에 에 접속하고 회원가입, 로그인한다.

netlify 상단 메뉴에서 dashboard로 이동한다.

Add new projects 버튼을 누른다.

index.html 파일을 netlify 웹페이지의 Upload you project files 부분에 끌어다 놓는다.

잠시 후 화면이 아래와 같이 바뀐다.

표시한 부분이 전 세계에서(핸드폰에서도 가능) 접속할 수 있는 url 주소이다.

브라우저에서 확인

netlify에서 알려준 주소를 클릭해 웹브라우저에 접속한다.

[사이트에 있는 동안 허용] 옵션을 선택하면, 현재 위치가 나타난다.

만약 웹브라우저 주소 입력 부분 오른쪽에 위와 같은 표시가 나타나면, “시스템 설정” 버튼을 클릭한다.

위와 같이 설정한다.

gps 좌표가 나타나는데 pc에는 GPS 센서가 없어 값이 매우 부정확하다.

스마트폰에서 사용

스마트폰에는 GPS 센서가 있다. 이 GPS 센서를 이용하면 PC에 비해 훨씬 정확하게 현재 위치를 가져올 수 있다.

pc용 크롬 브라우저에서 다음과 같이 qr 코드를 만들어 스마트폰에서 쉽게 접속할 수 있도록 하자.

사이트에서 오른쪽 클릭해 “이 페이지의 QR 코드 생성” 버튼을 누른다.

스마트폰에서 생성된 QR 코드를 인식해 쉽게 이 사이트에 접속할 수 있다.

스마트폰에서 gps를 켠다.

그리고 이 qr코드로 접속한다.

위치 권한 사용을 물어보면 “허용” 한다.

몇 초 후 스마트폰용 웹브라우저에 위도, 경도, 정확도의 정보가 보여진다.

그런데 스마트폰에서 보면 글씨가 너무 작아서 알아보기 힘들다.

index.html 파일을 고쳐 글씨를 크게 키워보자.

document.write(`<h1>위도: ${lat}</h1>`);        
document.write(`<h1>경도: ${lon}</h1>`);
document.write(`<h1>정확도: ${accuracy} 미터</h1>`);

h1 태그를 사용했기 때문에 크게 보인다.

netlify 에 가서 프로젝트를 열고 다시 파일을 drag & drop 한다.

잠시 후 수정된 내용이 반영된다.

이제 스마트폰을 들고 밖으로 다니며 위도 경도 값이 바뀌는 것을 확인하자.
